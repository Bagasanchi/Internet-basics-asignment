My Godot Game

How the game was made

This game was developed using the Godot game engine, which is an open-source platform for creating 2D and 3D games. I started by designing the game mechanics and creating simple graphics for the player character and obstacles. The game logic was implemented using GDScript, Godot's built-in scripting language. Throughout the development process, I tested the game frequently to ensure smooth gameplay and made adjustments based on my observations. Overall, this project was a great learning experience in game development with Godot.

I used the iframe tag to embed the game into this webpage. I exported the game files from Godot and placed them in my folder for the assignment.

For the godot files please check the "godot-build" folder in the project directory. There you can see all the files that were exported from godot. because when I exported my game from Godot, it automatically translated the GDScript code into HTML, CSS and JavaScript.

How to play the game

To play the game, use the arrow keys on your keyboard or use wasd. Both works totally fine. The goal of the game is to reach the end of the level while avoiding obstacles that spawn from both sides of the road. Click the Button below to load the game. Have Fun!
