My Godot Game Introduction

Overview

Welcome to the introduction page for my Godot game! This is a simple 2D game where the players goal is to reach the end of the level while avoiding obstacles that spawn from both sides of the road. The game is made for the purpose of learning godot while having fun. Although the game is simple, doesn't have any levels, and has no real rewards but while coding this I learned a lot about game development on Godot. Please go to the next page to test the game for yourself!
